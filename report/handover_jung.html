# 과제 우선순위 담당 부서·업체 현재 진행 상태
1헥토 코인 정책 당장 기획 · 파이낸셜 방향 확정 · 파이낸셜 협의 전
3네트워크 광고 연동 당장 기획 · 개발 · 애드팝콘 업체(애드팝콘) 확정 · 연동 미착수
4MMP 비용·연동 당장 기획 · 개발 · 미정 업체 미선정 · 비용 시뮬 필요
5CRM 툴 비용·연동 당장 기획 · 개발 · 미정 업체 미선정 · 비용 시뮬 필요
6어드민 (스마트컨트랙트 방) 당장 기획 · 개발 기능 기획 필요 · 미착수
2오퍼월 연동 오픈 이후 기획 · 개발 · 애드팝콘 미착수 (API 연동)
7기프티콘 연동 오픈 이후 기획 · 미정 업체 미선정
8게임 유형 추가 오픈 이후 기획 · 개발 미니게임 기획·개발 미착수
9퀴즈 유형 추가 오픈 이후 기획 · 개발 · 사업(브랜드) 구조 기획 필요 · 미착수
상태 범례 ■ 확정 ■ 일부 진행 ■ 미착수·미선정 📌 인계자 확정 필요

A. 당장 필요 — 오픈 전 완료 목표

1

헥토 코인 정책

당장
작업 내용
  • 초기에는 포인트로 운영한다.
  • 파이낸셜팀과 협의를 거친다.
  • 실제 코인 발행 시점에 포인트 → 코인 교환 기능을 제공한다.
담당 부서·업체
기획(차상호) · 파이낸셜(코인 발행 협의)
현재 진행 상태
정책 방향(포인트 선운영 → 교환)은 확정. 파이낸셜 협의 및 발행 일정 미확정.
핵심 포인트 — 오픈 시점에는 포인트 운영만 필수. 교환 기능은 코인 발행 확정 후 개발. 포인트↔코인 교환비율·정책은 📌 파이낸셜 협의 결과 확정.
3

네트워크 광고 연동

당장
작업 내용
  • 게임형에 사용할 네트워크 광고를 연동한다.
  • 광고 네트워크는 애드팝콘을 사용한다.
담당 부서·업체
기획 · 개발 · 애드팝콘(광고 네트워크)
현재 진행 상태
사용 업체(애드팝콘) 확정. SDK/연동 작업 미착수.
참고 — 2번 오퍼월과 동일하게 애드팝콘 사용 → 연동 작업·계약 창구를 묶어 진행하면 효율적.
4

MMP 비용 및 연동

당장
작업 내용
  • MMP(모바일 성과 측정) 업체 선정
  • 비용 시뮬레이션
  • 연동 작업
담당 부서·업체
기획 · 개발 · 📌 업체 미정 (예: AppsFlyer/Adjust 등 후보 검토)
현재 진행 상태
업체 미선정. 비용 시뮬레이션 및 연동 모두 미착수.
핵심 포인트 — 오픈 시 유입 성과 측정이 필요하므로 오픈 전 연동 완료가 목표. 예상 MAU/이벤트 볼륨 기준 📌 비용 시뮬레이션 선행.
5

CRM 툴 비용 및 연동

당장
작업 내용
  • CRM 툴 업체 선정
  • 비용 시뮬레이션
  • 연동 작업
담당 부서·업체
기획 · 개발 · 📌 업체 미정 (예: Braze/CleverTap 등 후보 검토)
현재 진행 상태
업체 미선정. 비용 시뮬레이션 및 연동 모두 미착수.
핵심 포인트 — 푸시·인앱 메시지 등 온보딩/리텐션 캠페인 기반. MMP(4번)와 데이터 연계 고려해 함께 검토.
6

어드민 — 스마트컨트랙트 방 관리

당장
작업 내용
  • 어드민에서 스마트컨트랙트 방 생성 기능
  • 생성된 방에 상금을 강제로 넣어주는(주입) 기능
담당 부서·업체
기획(차상호) · 개발
현재 진행 상태
기능 기획 필요. 화면·권한·처리 흐름 미정의, 개발 미착수.
핵심 포인트 — 스마트컨트랙트/상금 주입은 온체인 처리·권한 통제가 관건. 📌 상금 재원·주입 권한자·감사 로그 정책 확정 필요.

B. 오픈 이후 — 순차 진행

2

오퍼월 연동

오픈 이후
작업 내용
  • 스마트컨트랙트 오퍼월 미션을 위한 연동
  • 애드팝콘 API 연동 및 개발
담당 부서·업체
기획 · 개발 · 애드팝콘(오퍼월 API)
현재 진행 상태
미착수. API 연동 사양 정의 전.
참고 — 3번(네트워크 광고)과 같은 애드팝콘 → 계약·연동 창구 공유. 스마트컨트랙트 미션 구조와 6번 어드민 방 생성 기능이 선행 정리되어야 연결됨.
7

기프티콘 연동

오픈 이후
작업 내용
업체 선정 (리워드 지급 수단으로 기프티콘 제공)
담당 부서·업체
기획 · 📌 업체 미정
현재 진행 상태
업체 미선정. 연동 사양·정산 방식 미정.
참고 — 리워드 정책(헥토 코인·포인트)과의 관계, 지급 트리거 정의 필요.
8

오픈 이후
작업 내용
미니게임 기획 및 개발 (신규 게임 유형 확대)
담당 부서·업체
기획 · 개발
현재 진행 상태
미착수. 추가할 미니게임 종류·규칙 미정의.
참고 — 3번 네트워크 광고(게임형) 연동 완료 후 확장하는 것이 자연스러움.
9

퀴즈 유형 추가

오픈 이후
작업 내용
  • 어필리에이트 형태의 퀴즈 구조
  • 브랜드가 직접 들어와 예치하고 퀴즈를 내는 구조
담당 부서·업체
기획 · 개발 · 사업(브랜드 유치)
현재 진행 상태
구조 기획 필요. 브랜드 예치·정산 모델 미정의, 미착수.
참고 — 브랜드 예치금 관리·정산은 6번 어드민(상금 주입)·스마트컨트랙트 구조와 연계. 사업팀 브랜드 세일즈 병행 필요.
